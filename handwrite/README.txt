tripa 手写数据目录
==================

这个目录里的 CSV 是程序内置的手写数据（编译进 qrc:/handwrite），
格式与 getpattern 项目导出的 CSV 完全一致：

    第 1 行   : 字符标签。比如文件里只写一个 a，就表示这组笔画写的是 a。
                若标签是多字符（abcdef），程序会按 x 方向间隙把笔画切成对应份数。
    之后每行  : x,y,pressure
    1 个空行  : 笔画边界（一笔结束、下一笔开始）
    2 个空行  : 字符边界（下一个字开始）

pressure 是笔压，直接决定笔画粗细：线宽 = 该点 pressure × 当前字号 × 工具条上的
「笔宽」系数（默认 0.20，也就是 pressure 1.0 时线条有字号的 20% 粗）。
不写第 3 列也能用，那时按字高的固定比例画。

写字时"两个字之间没抬笔"不会丢字：程序会按 2 个空行的字符边界切，
切不动/多出来了就按几何修（丢掉抬笔跨页的连线、按阅读顺序重排、
合并或切开过宽的组），修不好才退回按 x 间隙猜。

用 tripa 自己采集（推荐）
------------------------

「手写 → 录入手写数据…」（Ctrl+Shift+G）就是采集入口，不用再开别的程序：

1. 在格子里写字（数位笔、鼠标都行，**一格一个字**）；
2. 在每格上面的框里填这个格写的是什么字（库里已经有的字会标「已有」，还缺的标「缺」）；
3. 点「保存 CSV…」 -> 存成 getpattern 同格式的 CSV（默认名自动避让 handwrite / handwrite1 …）；
4. 关掉对话框时会问要不要立刻载入，选「是」就马上能用 Ctrl+H 铺到文字上。

要点：

* **一格一个字**，所以字符边界是确定的（导出时写成 2 个空行），
  不必像 getpattern 那样靠识别结果 + 几何去猜哪几笔属于哪个字 ——
  那一步猜错会“从那个字往后整体错位一格”。
* **用数位笔写才有笔压**：每个点的压力会写进 CSV 第 3 列（depth），
  tripa 用它算笔画粗细（线宽 = 笔压 × 字号 × 工具条上的「笔宽」）。
  界面上有实时笔压读数和范围统计；
* **鼠标采的数据没有笔压**（固定记 0.5，和 getpattern 对鼠标的取值一致），
  存完 tripa 会明说“这一份没有按笔深度”，不会假装有；
* 勾上「每格单独存一个 CSV」时，文件名就是那个字（好.csv、好1.csv…），
  同一个字写两遍就成了两份样本（多份样本会被随机取用，字迹不会千篇一律）。

用 getpattern 采集也一样能用
---------------------------

格式完全一致，两边可以混用：

1. 打开 getpattern（UWP 手写采集程序），在画布上写字，点 Recognize text，
   把识别结果改成你要的字符；
2. 点 Save pattern，导出 CSV；
3. 把 CSV 放到一个目录里，在 tripa 里用「手写 → 载入手写数据（CSV 目录）」
   指定这个目录 —— 子文件夹会被递归搜索，按人/按次分层的目录直接选外层即可。

同一个字符可以有多份 CSV（比如你写了两遍 a），tripa 会随机取用其中一份，
字迹就不会千篇一律。

内置数据
--------

* a.csv … z.csv 由 tools/make_sample_pattern.py 生成，是程序自带的示例字母，
  用来保证"装上就能看到效果"。要换成真正的手写体，直接用自己的 CSV 覆盖即可
  （同一个字符可以放多个文件）。

逐字基线 / 大小校正（同名 xml）
------------------------------

手写样本的包围盒底边默认压在基线上，带下伸部的字（g/y/p/q/j）会偏高，
混进了抬笔连线或被切错的样本会偏小。用「手写 → 调整手写基线 / 大小…」
逐字调，改动会写成与 CSV 同名（去扩展名）的 xml：

    handwrite23.csv   ->   handwrite23.xml

    <?xml version="1.0" encoding="UTF-8"?>
    <tripaHandwriting version="1" csv="handwrite23.csv">
      <!-- baseline 单位 = 字身高的比例，正值往下沉；index 从 0 起（第 1 行标签里的位置） -->
      <char index="37" label="好" baseline="0.0310" size="0.8820"/>
    </tripaHandwriting>

* 载入 CSV 时会自动读回，不用每次重调；只有真调过的字才会写进去；
* 删掉 xml = 把那批校正清零，CSV 本身不受影响；
* 内置数据（qrc:/handwrite）是只读的，调了存不下来，程序会明确提示；
* 手写改标签（第 1 行）会让 index 对不上，改之前先想清楚。
